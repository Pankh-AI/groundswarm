Every number on this page comes straight from Ollama's own OpenAI-compatible /v1/chat/completions response (usage.* for tokens, choices[0].logprobs for perplexity), recorded on OllamaClient.calls at the moment each request returns. This is local inference — no Claude API tokens are spent running this scenario; this page exists so token/latency/confidence cost of the swarm itself is visible, not guessed at. Perplexity is exp(-mean(token logprob)) over each call's generated tokens — lower means the model was more confident in the exact tokens it produced; it says nothing about whether those tokens are factually correct, that's what the Verifier is for.
