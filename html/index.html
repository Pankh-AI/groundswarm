Groundswarm — Project Hub

Open source · early / architecture & research phase · last updated 2026-08-13
A swarm of OpenClaw-based agents, coordinated by a new orchestrator, whose combined output is independently re-checked against live primary sources before anything is reported as fact. Not SwarmBench, not a fork of any proprietary task-package format, built on OpenClaw (MIT) as the worker runtime plus a new orchestrator and verifier of Groundswarm's own. See README for the full pitch and LICENSE for terms.

Status

⚠ Early — architecture and licensing decisions made, orchestrator, verifier and memory not yet implemented beyond the single-domain capstone prototype the verification pattern was proven on. Literature survey, market survey, SWOT, similar-projects, name-availability, and memory-landscape research completed 2026-08-13; see audit log for the full run record. Published as Pankh-AI company work, Copyright 2026 Pankh-AI, under an existing Pankh-AI GitHub org. One decision remains open: confirmation of the first proof-case domain. A fourth component, Memory, a scoped and verified shared knowledge store, has been added to the architecture (ADR-007), checked against 9 agent-memory products and 2 research proposals, and confirmed as a genuine, unaddressed gap, not yet built. See decisions.
