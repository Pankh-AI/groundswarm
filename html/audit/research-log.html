What each thread was asked

Literature survey: hallucination detection/retrieval-grounding, LLM-as-judge failure modes, multi-agent error compounding, and whether any benchmark scores verified-vs-plausible multi-agent output. Full brief and results on the literature survey page.

Market survey: 7 multi-agent orchestration frameworks and 12 LLM verification/eval/observability companies, license/business model and verification depth for each, synthesized into a SWOT. Full brief and results on the market survey page and SWOT page.

Similar projects & name check: existing open-source projects combining swarm scale with independent verification, plus a "Groundswarm" collision check across GitHub, npm, PyPI, web search, and DNS. Full brief and results on the similar-projects page.

Memory landscape (round 2): whether any agent-memory product or research proposal combines five specific design properties, validity/blast-radius scoping, a deterministic pre-merge gate, review-gated high-stakes writes, tiered token-aware loading, and TTL/supersedes staleness, checked against 9 products and 2 papers. Full brief and results on the memory landscape page.

Scope note: what was deliberately not researched

The originating request also asked to cross-check the project owner's own GitHub activity for context ("use pankaj github if possible"). This was not delegated to any research agent. A local check (git remote -v, git config) found no GitHub remote configured on this repository, only a local git identity that does not match the name this project is meant to be published under, and the user separately instructed "no sensitive info" immediately after that check surfaced a personal email address in tool output. Rather than search the web for a common name and risk either exposing that data or misattributing a different person's public repositories to this project, that thread was dropped and left for the user to supply a confirmed public handle directly. No personal identifying information (name, email, or otherwise) was passed to any research agent or written into any file in this research round. See limitations for the full list of open gaps.

Method

Each agent was dispatched with a self-contained prompt (full project context restated, since agents share no memory with this conversation or each other), instructed to use web search aggressively, prioritize primary sources (arXiv papers, official docs, pricing pages) over secondary blog coverage, and explicitly told not to fabricate findings, if search results were thin, to say so rather than guess. Every claim reproduced in the html/ pages carries its source link back to where the agent found it; nothing in this research round was asserted without a citation traceable to the original agent output.
